# QS-Window-Pill
A QS powered pill designed to replace CSD/SSD on WM's for mouse-driven users.
- Draggable with mouse/stylus/touch.
- Tiling and floating switching buttton.
- Close, minimize (moves to invisible workscape), maximize
Note that this is ai coded and only tested on hyprland.
Extract this into /home/{USER}/.config/quickshell/
